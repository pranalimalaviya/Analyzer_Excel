# Analyzer – Excel Data Analysis Project

Welcome to the **Analyzer** project!

This Excel project is designed to demonstrate practical skills in **data analysis, descriptive statistics, regression analysis, Pivot Tables, 
What-If Analysis, and dashboard creation** using Microsoft Excel.

The project uses a sales dataset containing customer, region, product, sales, quantity, discount, profit, and order-date information.

## Project Overview

The **Analyzer** workbook analyzes sales data to identify important business insights and performance trends.

The project focuses on:

* Data organization and cleaning
* Descriptive statistics
* Sales and profit analysis
* Linear regression
* Pivot Table analysis
* What-If Analysis
* KPI calculation
* Customer analysis
* Dashboard creation

## Workbook Structure

The workbook contains four main worksheets:

### 1. Dataset

The **Dataset** sheet contains the main sales data used throughout the project.

It includes **200 records** with columns such as:

| Column           | Description                    |
| ---------------- | ------------------------------ |
| Customer_ID      | Unique customer identification |
| Customer_Name    | Name of the customer           |
| Region           | Sales region                   |
| Product_Category | Category of the product        |
| Sales            | Sales amount                   |
| Quantity         | Quantity purchased             |
| Discount         | Discount applied               |
| Profit           | Profit generated               |
| Order_Date       | Date of the order              |
| Timestamp        | Current timestamp              |

The dataset is used as the source for calculations, statistics, Pivot Tables, and the dashboard.

### 2. Analysis & Statistics

This worksheet contains statistical analysis of the dataset.

#### Descriptive Statistics

The following statistical measures are calculated for:

* Sales
* Quantity
* Discount
* Profit

Measures include:

* Count
* Mean
* Standard Error
* Median
* Standard Deviation
* Sample Variance
* Kurtosis
* Skewness
* Range
* Minimum
* Maximum
* Sum

#### Linear Regression

A **Linear Regression analysis** is performed to study the relationship between:

**Sales → Profit**

The regression section includes:

* Multiple R
* R Square
* Adjusted R Square
* Standard Error
* Observations
* ANOVA
* Regression coefficients
* P-value
* Confidence intervals

The analysis helps determine how strongly sales are related to profit.

### 3. Pivot & What-If

This worksheet contains two important Excel analysis techniques.

#### Pivot Table

A Pivot Table is created to analyze:

**Total Sales by Region and Product Category**

The analysis allows sales to be compared across:

* Central
* East
* North
* South
* West

and product categories:

* Books
* Clothing
* Electronics
* Furniture
* Office Supplies

A Grand Total is also provided.

#### What-If Analysis

A What-If Analysis is used to examine how different **discount rates** can affect projected total profit.

The model evaluates discount rates such as:

* 5%
* 10%
* 15%
* 20%

This helps understand the potential impact of changing discount policies on profitability.

### 4. Dashboard

The **Dashboard** provides an executive-level summary of the sales data.

It contains important Key Performance Indicators (KPIs), including:

* Total Sales
* Total Profit
* Average Profit per Sale
* Order Count

It also includes a **Top Customer Spotlight**, showing information such as:

* Customer Name
* Total Purchases
* Order Count
* Primary Region

The dashboard is designed to provide important information quickly without requiring users to examine the entire dataset.

## Key Results

Based on the analysis:

* **Total Sales:** approximately **195,217.76**
* **Total Profit:** approximately **68,287.01**
* **Total Quantity Sold:** **1,999**
* **Number of Orders:** **200**
* **Average Sales:** approximately **976.09**
* **Average Profit:** approximately **341.44**

The regression analysis shows a positive relationship between sales and profit, with an **R Square of approximately 0.598**, 
meaning sales explain around 59.8% of the variation in profit in this model.
